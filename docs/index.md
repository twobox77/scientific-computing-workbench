# SCW — Scientific Computing Workbench

以 Python 撰寫的科學計算工作台：在 NumPy 與 SciPy 之上自行定義數學型別，
並以可重現、可測試的工程方式打包。

- 想快速上手：看 [Installation](installation.md) 與 [Usage](usage.md)。
- 想看支援的公開介面：看 [Public API](api.md)。
- 想知道哪些介面凍結、如何棄用：看 [API stability](stability.md)。
- 想看設計理由：看 [Architecture decisions](architecture/decisions.md)。
- 想離線「欣賞與操作」：看 [離線使用](offline.md)。
- 想看繪圖成果：看 [Gallery](gallery.md)。

數學主題：[向量空間](mathematics/vector-spaces.md)、
[數值方法](mathematics/numerical-methods.md)、
[符號代數](mathematics/symbolic.md)、
[視覺化](mathematics/visualization.md)、
[流形](mathematics/manifolds.md)、
[物理模擬](mathematics/physics.md)、
[實驗追蹤](mathematics/experiments.md)。
