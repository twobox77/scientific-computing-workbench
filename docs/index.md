# SCW — Scientific Computing Workbench

A Python workbench for scientific computing: typed mathematical objects on top
of NumPy and SciPy, with reproducible, testable tooling.

See the [Quickstart](tutorials/quickstart.md) to get started, the
[Public API](api.md) reference for the supported surface, and
[Architecture decisions](architecture/decisions.md) for the design rationale.
Contributors should read [Development](development.md); the
[Phase 1 acceptance report](phase1-acceptance.md) records the formal close-out.

The [numerical methods](mathematics/numerical-methods.md) page covers the
factorizations and the ODE solver; the [visualization](mathematics/visualization.md)
page covers the optional Matplotlib adapter.
